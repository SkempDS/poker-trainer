德州扑克 · 桌面版
==================

怎么玩
------
双击「德州扑克.exe」就行。会打开一个没有地址栏的窗口。

第一次打开会自动在桌面和开始菜单放一个「德州扑克」的快捷方式，
以后从快捷方式进也可以。窗口第一次开比后面慢一两秒，属正常。

需要什么
--------
只需要机器上有 Chrome 或者 Edge 之一。
Windows 10/11 自带 Edge，所以一般不用额外装东西。

如果两个都没有，程序会弹窗提示你装一个。

玩法说明
--------
开局前可以自己填：起始筹码、小盲、大盲、AI 人数（1~5 个，
即 2~6 人桌）。

- 底部的滑块和输入框都能调加注金额，输入框可以手打具体数字。
- 右侧「对局记录」在每一手结束后才公开对手的底牌。
- 顶上的「复盘」按钮可以回顾每一手的每个决策点，标出你的选择
  和理论最优选择。

卸载
----
双击「卸载.bat」。

它在删掉桌面和开始菜单的快捷方式，以及缓存目录
（%LOCALAPPDATA%\TexasHoldem）。删完把整个文件夹一起删掉就干净了。

说明
----
- 玩的手牌记录只在本次窗口内有效，关掉窗口就清空了。
- 想要带图标的独立应用体验，需要拿 Chrome 或 Edge 用，这是应用窗口
  模式的固有样子，不是程序的问题。
